# MultiVendorX — Homepage Redesign

A modern redesign of the [multivendorx.com](https://multivendorx.com/) homepage. It is static HTML, CSS and JS with no build step.

## Run
Open `index.html` in a browser, or:

```bash
npx serve .
```

## Structure
- `index.html`: page markup (all sections)
- `assets/styles.css`: design tokens, layout and responsive rules (brand purple `#5007aa`, Mulish font)
- `assets/main.js`: feature tabs, mobile menu, sticky nav and scroll reveal

## Sections
Announcement bar · Sticky nav with dropdowns · Hero with dashboard mockup · Stats strip · Interactive feature tabs (7 categories) · Why MultiVendorX · Marketplace types · "Power of 5" bento grid · Pricing (Starter $149 / Agency $299) · Testimonials · Blog · FAQ accordion · CTA · Footer

Copy, pricing and links are taken from the current live homepage.
