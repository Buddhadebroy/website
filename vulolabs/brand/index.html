Brand Guidelines

The colors, type, logo and UI components that make up the Vulo Labs design system — pulled directly from the tokens the live site runs on.

Color

One interactive color — navy blue — carries buttons, links and emphasis. Orange is reserved for accents inside dark sections. Everything else is neutral.

Don't
  • Recolor the mark outside navy / white.
