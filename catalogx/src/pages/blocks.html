How to use these blocks

1Add the blocks to your pages

Open the WordPress block editor, search for the block you need (for example Add to Enquiry or Add to Quote), and insert it into any page or post.

2Customize the appearance

Tailor the button text, style, and placement to match your store's theme for a seamless look.

3Boost customer interaction

Visitors can now enquire about products or request quotes, which makes your store more useful and more profitable.
