About

Every message, actually delivered.

VuloMail is a free WordPress plugin that sends your site's email and SMS through the provider you already use, fails over to a backup, logs every message, and texts you when something breaks.

The problem

Why we built it.

WordPress sends password resets, order receipts and contact form notifications through your host's mail server. When one of those messages fails, nothing tells you. The customer simply never gets it.

We built VuloMail so delivery is something you can see and rely on: the provider you already pay for, a backup when it has a bad day, a log that explains every failure in plain words, and a text message when something breaks.

It is free, with no account, no subscription and no Pro edition, because getting your own site's email delivered shouldn't be an upsell.

Principles

Five rules we build by.

They decide every feature, and they are why VuloMail stays out of your way until you need it.

01

Unconfigured means untouched

Activating VuloMail changes nothing. WordPress keeps sending as it always has until you set a primary connection.

02

Adapters never throw, never leak

A provider failure becomes a clean, failed result with credentials scrubbed out of the error text.

03

Secrets never leave the server

Saved keys come back masked. The browser never holds the real value, so it can never send it anywhere.

04

One log row per message

Primary, backup, last resort: every attempt is recorded on a single entry, not scattered across many.

05

Privacy by default

Message bodies aren't stored unless you opt in. Recipients can be masked. Old entries prune themselves.
