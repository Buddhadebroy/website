Email delivery

Your wp_mail(), through a real email service.

Password resets, order confirmations and form notifications go out through the provider you choose: any SMTP server, an email API such as SendGrid, Postmark or Resend, or a preset such as Gmail or Amazon SES. You don't change anything in the plugins that send them.

Try it

What happens when something breaks?

Flip the switches to take connections down. Each message lands in the log once, with every attempt listed.

The sender

The From address is the most common reason providers reject mail.

Most providers only accept an address you have verified with them. VuloMail replaces WordPress's default sender with yours, and only overrides another plugin's address if you tell it to. The same sender also applies when WordPress's own mailer ends up sending.

Settings explained

Six settings. That's the whole page.

Send email through VuloMail

Default: On

When on, your site's email goes through your primary connection. Switch off to rule VuloMail out while investigating. Connections are kept.

Fall back to the WordPress default mailer

Default: On

If primary and backup both fail, hand the email to WordPress instead of dropping it.

Sender email

Default: Empty

Replaces wordpress@yourdomain. Use an address your provider has verified.

Sender name

Default: Empty

Replaces “WordPress” so recipients see your business name.

Always use this sender email

Default: Off

Override a From address set by another plugin, if your provider rejects it.

Always use this sender name

Default: Off

One consistent name on every email.

Under the hood

It reads wp_mail() exactly the way WordPress does.

Every recipient shape

A string, a comma list or an array; a@b.c or Name <a@b.c>.

Every header shape

Newline strings, lists or associative arrays. From, Cc, Bcc, Reply-To and Content-Type are understood; the rest are kept.

Attachments

Strings, lists or name => path. Unreadable files are dropped; API providers accept up to 20 MB in total.

Injection guards

Any address, name or header containing a line break is dropped. Header names must be plain.

Source labels

The plugin or theme that called wp_mail() is recorded, or “core” for WordPress itself.

Core's filters, in core's order

wp_mail_from, wp_mail_from_name, wp_mail_content_type and wp_mail_charset all still apply.

Which emails does this cover?

Everything sent with WordPress's standard email function: password resets, new user emails, comment notifications, WooCommerce order emails, contact-form notifications and emails from most plugins.

Good to know

A plugin that talks to an email service directly, without wp_mail(), is not affected.

“Sent” means your provider accepted the message. Inbox delivery is reported in your provider's dashboard. Use the Provider ID from the log to look it up.

A plugin can opt a single message out with the vulomail_should_handle_email filter.
