Comparison

VuloMail vs SMTP Mailer.

SMTP Mailer does one thing: it sends WordPress email through an SMTP server you configure. There are no API connections, no backup and no alerts, and the email log is part of a $59.99 add-on bundle. It's a fine choice if you want the smallest possible plugin. VuloMail does far more, still for free.

Strengths

Where each one wins.

Where SMTP Mailer is stronger

Very small and simple: one settings screen for one SMTP server.

Where VuloMail is stronger

Native API connections for 22 email services, which still work when a host blocks SMTP ports.

A free email log, backup connection, failure alerts and diagnostics.

SMS alerts and WooCommerce texts.

Verdict

Which one should you pick?

Choose SMTP Mailer if

You want the smallest possible plugin and only ever use one SMTP server.

Choose VuloMail if

You want to see what was sent, have a backup, or send over an API instead of SMTP.
