Under the hood

It reads wp_mail() exactly the way WordPress does.

Every recipient shape

A string, a comma list or an array; a@b.c or Name <a@b.c>.

Every header shape

Newline strings, lists or associative arrays. From, Cc, Bcc, Reply-To and Content-Type are understood; the rest are kept.

Attachments

Strings, lists or name => path. Unreadable files are dropped; API providers accept up to 20 MB in total.

Injection guards

Any address, name or header containing a line break is dropped. Header names must be plain.

Source labels

The plugin or theme that called wp_mail() is recorded, or “core” for WordPress itself.

Core's filters, in core's order

wp_mail_from, wp_mail_from_name, wp_mail_content_type and wp_mail_charset all still apply.
