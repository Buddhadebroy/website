Comparison

VuloMail vs Solid Mail.

Solid Mail, formerly WP SMTP, is free and does the basics well: five API providers plus manual SMTP, multiple connections chosen by From address, a fallback, and an email log. It was last updated in May 2026 and is listed as tested up to WordPress 6.9.10, behind the current 7.1.3. VuloMail supports far more services and adds alerts, diagnostics and SMS.

Strengths

Where each one wins.

We list theirs first. If one of these matters most to you, it should decide it.

Where Solid Mail is stronger

Routes different From addresses to different connections.

On WordPress.org since 2012, with 60,000 active installs.

Where VuloMail is stronger

22 email APIs against Solid Mail's five, plus 18 SMTP presets including Gmail and Microsoft 365.

Failure alerts, resend from the log, and a Diagnostics screen with an SPF and DMARC check.

Actively released and tested against the current WordPress 7.1.3.

SMS alerts and WooCommerce texts.

Verdict

Which one should you pick?

Choose Solid Mail if

You use one of its five providers and need per-sender routing.

Choose VuloMail if

Your provider isn't SendGrid, Mailgun, Brevo, SES or Postmark.

You want alerts when sending fails, or SMS for your store.

Switching

Moving from Solid Mail.

01

Add the same account

Add the provider you use in Solid Mail as a VuloMail connection. Nothing changes until you set it as primary.

02

Set it as primary

Optionally add a backup connection, so a second provider takes over if the first fails.

03

Send a test

Tools → Send a test email goes through live routing. Diagnostics confirms your SPF and DMARC records.

04

Deactivate Solid Mail

Two plugins handling the same email compete for it. VuloMail's Diagnostics flags any it recognises.
