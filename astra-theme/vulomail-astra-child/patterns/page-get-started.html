Get started

Five steps. About five minutes.

You need WordPress 6.4+, PHP 7.4+, an administrator account, and an email account: any SMTP server, one of 22 email APIs such as SendGrid or Postmark, or a one-click preset such as Gmail or Amazon SES.

1

Install and activate

a.In WordPress go to Plugins → Add New.

b.Search for VuloMail, or choose Upload Plugin and pick the zip file.

c.Click Install Now, then Activate. A VuloMail item appears in the menu.

Nothing changes yet. WordPress keeps sending email exactly as before.

2

Add an email connection

a.Go to VuloMail → Settings. It opens on Connections.

b.In the Email section click Add email connection.

c.Choose your provider, fill in what it asks for, and click Save connection.

Saved keys are encrypted immediately and never shown again.

What each provider needs

3

Set it as primary

a.Your connection is saved but not in use yet.

b.Click Set as primary on its row.

c.Optional: add a second connection and click Set as backup.

This is the moment VuloMail starts routing your email.

4

Set your sender

a.Open the Email sub-tab.

b.Enter a Sender email your provider has verified, like hello@yourdomain.com.

c.Add a Sender name, such as your business name.

Changes save by themselves a moment after you make them.

5

Send a test

a.Go to VuloMail → Tools.

b.In Send a test email, check the address and click Send test.

c.Look in that inbox, and the spam folder too.

If it fails, the message on screen says why. Diagnostics will tell you what to fix.

Words you'll see everywhere

A tiny glossary.

Connection

One account with an email service or SMS provider that you've added

Primary

The connection used for every message

Backup

The connection tried when the primary fails

WordPress default mailer

How WordPress sends email on its own, through your web server

Last resort

Handing an email to the WordPress mailer when primary and backup both fail

Sent

A provider accepted the message. It doesn't prove the message reached the inbox

Failed

No connection could send the message

Sent via backup

The primary failed and something else delivered the message
