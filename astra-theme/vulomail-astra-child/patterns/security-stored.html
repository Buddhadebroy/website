Everything VuloMail stores, in your own database

{prefix}vulomail_logs

Table

One row per message. Bodies are NULL unless you store content.

vulomail_settings

Option

Every setting you can change in the admin.

vulomail_connections

Option

Your connections, with secret fields encrypted.

vulomail_key_material

Option

Random half of the encryption key material.

vulomail_prune_logs

Daily event

Deletes entries older than your retention period.

No post types, no user meta, no post meta. On uninstall, nothing is removed unless you chose Delete everything. Then the table, options, transients and scheduled event are all cleared.
