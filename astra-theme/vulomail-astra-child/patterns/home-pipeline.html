How a message travels

01

Your site sends an email.

WordPress, WooCommerce, your forms, any plugin calling wp_mail(). Nothing in those plugins changes.

02

VuloMail picks it up.

It reads every header shape WordPress accepts, applies your sender, guards against header injection and labels the plugin that sent it.

03

Your primary tries first.

The message goes to the provider you chose. If it is down, rejects the key, or times out, VuloMail doesn't give up.

04

The backup takes over.

Your second connection is tried straight away. If both fail, WordPress's own mailer can still try as a last resort.

05

One entry in the log.

Every attempt is kept on a single row, so you can see exactly what happened. Optionally, a text tells you something failed.
