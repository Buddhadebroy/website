# page-templates/

VuloMail has no custom full-page templates yet — every page is the default
Astra/Kadence template with synced header/footer patterns (see `patterns/`).
This folder exists so the theme matches the shared structure used across the
other VuloLabs child themes. Add a `template-{page}.php` here if a page ever
needs its own full-width canvas (the way VuloForm's `template-compare.php` or
VuloPilot's `template-home.php` do), and register it the same way.
