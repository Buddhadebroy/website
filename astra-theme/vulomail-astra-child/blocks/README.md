# blocks/

VuloMail has no theme-specific custom blocks yet — its pages are built from
Kadence synced patterns (see `patterns/` and `inc/patterns.php`) rather than
bespoke Gutenberg blocks. This folder exists so the theme matches the shared
structure used across the other VuloLabs child themes. If VuloMail gains its
own blocks (like VuloForm's compare-tabs or VuloPilot's checklist), they go
here, each in its own sub-folder, registered from `inc/blocks.php`.
